# 끝말잇기 한방봇 (Hanbang Bot)

한방 단어를 꽂는 5단계 봇과 붙는 1:1 끝말잇기. 796,750 단어 사전, 표준 두음법칙, 5단계 난이도.

- 라이브: **https://hanbang-bot.onrender.com**
- 저장소: https://github.com/Eomukim/hanbang-bot

## 무엇이 들어 있나

| 항목 | 내용 |
| --- | --- |
| 단어 사전 | 공개 사전 덤프와 끄코 유틸리티 오픈DB를 병합한 2글자 이상 순수 한글 796,750개 |
| 두음법칙 | ㄹ+ㅑㅒㅕㅖㅛㅠㅣ → ㅇ, 그 밖의 ㄹ → ㄴ, ㄴ+ㅑㅒㅕㅖㅛㅠㅣ → ㅇ (표준 전체) |
| 한방 단어 | 끝 글자(와 두음 변환 글자)로 시작하는 후속 단어가 0개인 단어 1,701개 |
| 유도 단어 | 후속 단어가 1~5개뿐인 글자로 끝나는 단어 2,956개 |
| 내 단어장 | 사전에 없는 단어를 직접 등록·삭제, `localStorage`에 저장, 봇 판정에도 즉시 반영 |
| 봇 | 5단계. Lv.4 극악은 한방 단어가 있으면 100% 즉시 사용, Lv.5 지옥은 빌드 타임 루트전 그래프로 수를 읽는다 |

## 규칙

- 2글자 이상 한글 단어만. 이미 나온 단어는 다시 쓸 수 없다.
- 앞 단어의 끝 글자로 시작해야 하며, 두음법칙 변환 글자도 인정된다(`력` → `역`).
- 자기 차례 제한 시간(10/15/20초)을 넘기면 패배. 이을 단어가 없으면 그 자리에서 패배.
- 점수 = (글자수² + 글자수×4) × 콤보 배수(최대 2.5) × 미션 배수.
- 미션 글자는 가·나·다·라·마·바·사·아·자·차·카·타·파·하 14종 중 하나로 시작한다. 단어에 1번 들면 +50%, 2번 겹치면 ×2, 3번이면 ×3으로 중첩된다(`미션 ×2` 표시).
- 미션 글자는 성공(미션 글자가 든 단어 입력) 전까지 그대로 유지되고, 나나 봇이 성공하는 순간 직전과 다른 다음 미션 글자로 바뀐다.

## 난이도

| 단계 | 봇의 행동 |
| --- | --- |
| Lv.1 쉬움 | 한방 단어 금지, 후속 단어가 많은 2~3글자 위주, 1.5~2.5초 응답 |
| Lv.2 보통 | 가끔 긴 단어, 4턴 이후에만 낮은 확률로 한방 |
| Lv.3 어려움 | 후속 1~3개인 글자로 몰아넣고, 4턴 이후 85% 확률로 한방 |
| Lv.4 극악 | 한방이 있으면 100% 즉시 사용. 없으면 최소 후속 글자·장문으로 0.2~0.5초 압박 |
| Lv.5 지옥 | 루트전 그래프 + 실시간 수읽기. 한방 즉사 → 강제 필승 → 위험한 수 배제 → 압박·미션·장문, 0.15~0.4초 |

봇 이름은 단계별로 한방봇 주니어 · 한방봇 · 한방봇 X · 한방봇 극악 · 한방봇 지옥이다.

### Lv.5 지옥이 수를 읽는 방법

`build/build_data.py` 가 796,750단어의 음절 전이 그래프(표준 두음법칙 포함)를 역방향으로 분석해
`data/stats.json` 의 `graph` 에 남긴다. 노드는 '이어야 할 글자', 간선은 그 글자로 낼 수 있는 단어다.

- **승리(W)** = 지는 자리로 보낼 수 있는 글자, **패배(L)** = 모든 수가 이기는 자리로 이어지는 글자, **무승부(D)** = 둘 다 아닌 글자.
- 깊이는 완전한 대국에서 끝까지 걸리는 수. 빌드 때마다(월간 오픈DB 갱신 포함) 자동으로 다시 계산된다.
- 앱은 이 상태와 함께 **지금까지 나온 단어(`used`)** 를 반영해 실제로 검증한 수만 둔다.
  1. 한방 즉사(상대 후속 0) — 미션 중첩·장문 우선
  2. 강제 필승 — 내 수 → 상대 모든 응수 → 내 한방/필승을 하나하나 확인
  3. 위험한 수 배제 — 상대에게 한방 각이나 필승 자리를 넘기는 수는 피한다(피할 수 있을 때)
  4. 압박·점수 — 상대 후보가 1~3개뿐인 글자로 몰고, 같은 조건에서는 미션·장문으로 점수를 챙긴다
- 판단은 한 수당 평균 2ms 안쪽, 응답 텀은 0.15~0.4초다.

## 구조

```
index.html          화면 뼈대
css/style.css       아케이드 UI (모바일 390px 우선, 키보드 높이 대응)
js/rules.js         한글 음절 분해 · 두음법칙
js/data.js          사전 로드(스트리밍) · 구간 색인 · 한방/유도 판정 · 내 단어장
js/engine.js        턴 진행 · 판정 · 점수 · 타이머
js/bot.js           5단계 봇 전략(루트전 수읽기 포함)과 대사
js/audio.js         Web Audio 효과음(음원 파일 없음)
js/store.js         localStorage 설정 · 내 단어장 · 전적
js/ui.js            화면 조립, 입력, 결과
build/build_data.py 단어 원본 → data/words.txt + data/stats.json(+ 음절 대전 그래프)
build/collect_kkuko.py 오픈DB(공개 API) 단어 수집
tools/verify.py     headless Chromium 검증(로컬/라이브)
```

사전은 시작 음절마다 연속 구간을 이루도록 정렬해 두어, 브라우저에서는 이진 탐색과 구간 조회만으로
판정·후속 단어 수·봇 후보를 계산한다. 별도 색인 파일 없이 796,750 단어가 즉시 조회된다.

## 데이터 다시 만들기

```bash
curl -L -o db.sql https://raw.githubusercontent.com/JJoriping/KKuTu/master/db.sql
python3 build/build_data.py db.sql                      # db.sql 만으로 기존 사전 재생성
python3 build/collect_kkuko.py                          # 오픈DB 단어를 build/kkuko-words.txt 로 수집
python3 build/build_data.py db.sql build/kkuko-words.txt # 두 원본 병합 + 한방/유도 재계산
```

`build/collect_kkuko.py` 는 끄코 유틸리티의 공개 오픈API를 시작 음절별로 호출한다.
받은 원본(`build/kkuko-words.txt`, `build/kkuko-raw.jsonl`)은 저장소에 커밋하지 않는다.

## 검증

```bash
python3 tools/verify.py --local
python3 tools/verify.py --url https://hanbang-bot.onrender.com
```

로컬/라이브 모두에서 콘솔·페이지 에러 0, 가로 오버플로 0, 두음법칙 입력, 중복 차단,
내 단어장 반영, 1단계 한방 금지, 4단계 극악 한방 즉사, 5단계 카드 배치, Lv.5 지옥의
한방 즉사·상대 한방 각 회피·강제 필승 검증, 4단계 기준 localStorage 호환, 모바일 키보드 높이 레이아웃을 확인하고
스크린샷을 `downloads/`에 남긴다.
