# 끝말봇 — 끝말잇기

말을 이어가는 5단계 봇과의 1:1 끝말잇기. 796,750 단어 사전, 표준 두음법칙, 5단계 난이도.

- 라이브: **https://kkeutmalbot.onrender.com**
- 저장소: https://github.com/Eomukim/kkeutmalbot

## 무엇이 들어 있나

| 항목 | 내용 |
| --- | --- |
| 단어 사전 | 공개 사전 덤프와 오픈DB를 병합한 2글자 이상 순수 한글 796,750개 |
| 두음법칙 | ㄹ+ㅑㅒㅕㅖㅛㅠㅣ → ㅇ, 그 밖의 ㄹ → ㄴ, ㄴ+ㅑㅒㅕㅖㅛㅠㅣ → ㅇ (표준 전체) |
| 한방 단어 | 끝 글자(와 두음 변환 글자)로 시작하는 후속 단어가 0개인 단어 1,701개 |
| 유도 단어 | 후속 단어가 1~5개뿐인 글자로 끝나는 단어 2,956개 |
| 결과 화면 | 승리·패배·시간 초과·포기 모두 이번 대국의 난이도(`Lv.5 지옥` 등)를 배지로 표시하고, `배틀 내역 (N수)` 버튼으로 그 판에 주고받은 수를 연다 |
| 배틀 내역 | 결과 카드 안에서 턴 번호·나/봇·입력한 단어·획득 점수·그 수의 태그(한방·미션·외통수·필승 라인·압박·외래어 등)를 순서대로 보여 준다. `max-height` + 세로 스크롤, 기본은 접힘. 0수로 끝나면 `주고받은 단어가 없어요` |
| 하드코어 모드 | 🔥 스위치 하나로 제한 시간 5초 고정 · 봇 선공 고정. 대전 헤더와 결과 화면에 전용 배지, 전적은 하드코어끼리 따로 기록 |
| 봇 | 5단계. Lv.4 극악은 한방 단어가 있으면 100% 즉시 사용, Lv.5 지옥은 빌드 타임 루트전 그래프로 수를 읽는다 |

## 규칙

- 2글자 이상 한글 단어만. 이미 나온 단어는 다시 쓸 수 없다.
- 앞 단어의 끝 글자로 시작해야 하며, 두음법칙 변환 글자도 인정된다(`력` → `역`).
- 자기 차례 제한 시간(10/15/20초)을 넘기면 패배. 이을 단어가 없으면 그 자리에서 패배.
- 점수 = (글자수² + 글자수×4) × 콤보 배수(최대 2.5) × 미션 배수.
- 미션 글자는 가·나·다·라·마·바·사·아·자·차·카·타·파·하 14종 중 하나로 시작한다. 단어에 1번 들면 +50%, 2번 겹치면 ×2, 3번이면 ×3으로 중첩된다(`미션 ×2` 표시).
- 미션 글자는 성공(미션 글자가 든 단어 입력) 전까지 그대로 유지되고, 나나 봇이 성공하는 순간 직전과 다른 다음 미션 글자로 바뀐다.

## 하드코어 모드

설정 화면의 **🔥 하드코어** 스위치를 켜면 Lv.1~5 어느 난이도에서든 같은 규칙이 붙는다.

- **제한 시간 5초 고정** — 내 차례마다 5초. 설정 화면의 시간 선택은 `🔒 5초 고정`으로 잠긴다.
- **봇 선공 고정** — 대국은 언제나 봇의 첫 단어로 시작한다(선공 선택은 `🔒 봇부터`로 잠긴다).
- **전용 배지** — 대전 중 상단 헤더와 결과 화면(승리·패배·시간 초과·포기 모두)에 `🔥 하드코어` 배지가 붙는다.
- **별도 전적** — 하드코어 대국은 일반 전적과 섞이지 않는다. 전적은
  `localStorage` 키(`kkeutmalbot.record.v1`)에 `3:hc`처럼 구분된 행으로 쌓여, 예전 기록도 그대로 읽힌다
  (이전 이름(`itda.record.v1`·`hanbang.record.v1`)으로 저장된 기록도 처음 한 번 옮겨 와 그대로 이어진다).

스위치를 끄면 기존 그대로다 — 10/15/20초, 나부터/봇부터를 자유롭게 고른다.

## 난이도

| 단계 | 봇의 행동 |
| --- | --- |
| Lv.1 쉬움 | 한방 단어 금지, 후속 단어가 많은 2~3글자 위주, 1.5~2.5초 응답 |
| Lv.2 보통 | 가끔 긴 단어, 4턴 이후에만 낮은 확률로 한방 |
| Lv.3 어려움 | 후속 1~3개인 글자로 몰아넣고, 4턴 이후 85% 확률로 한방 |
| Lv.4 극악 | 한방이 있으면 100% 즉시 사용. 없으면 최소 후속 글자 상위권에서 매 판 다르게 골라 0.2~0.5초 압박 |
| Lv.5 지옥 | 루트전 그래프 + 실시간 수읽기. 한방 즉사 → 5~7수 강제 필승 → 위험한 수 전수 평가(독배) → 압박·미션·장문. 매 수는 최상위권 후보 중에서 골라 같은 글자에도 단어가 겹치지 않는다. 0.15~0.4초. 봇 선공이면 이기는 시작 글자로 연다 |

봇 이름은 단계별로 끝말봇 주니어 · 끝말봇 루키 · 끝말봇 마스터 · 끝말봇 극악 · 끝말봇 지옥이다.

### Lv.5 지옥이 수를 읽는 방법

`build/build_data.py` 가 796,750단어의 음절 전이 그래프(표준 두음법칙 포함)를 역방향으로 분석해
`data/stats.json` 의 `graph` 에 남긴다. 노드는 '이어야 할 글자', 간선은 그 글자로 낼 수 있는 단어다.

- **승리(W)** = 지는 자리로 보낼 수 있는 글자, **패배(L)** = 모든 수가 이기는 자리로 이어지는 글자, **무승부(D)** = 둘 다 아닌 글자.
- 깊이는 완전한 대국에서 끝까지 걸리는 수. 빌드 때마다(월간 오픈DB 갱신 포함) 자동으로 다시 계산된다.
- 앱은 이 상태와 함께 **지금까지 나온 단어(`used`)** 를 반영해 실제로 검증한 수만 둔다.
  1. **한방 즉사**(상대 후속 0) — 어떤 한방이든 즉사이므로 장문 상위권(최장 - 5글자) 안에서 고른다. 끝 글자가 같으면 그중 점수가 가장 높은 단어를 쓴다.
  2. **5~7수 강제 필승** — 내 수 → 상대 모든 응수 → 내 한방/필승을 하나하나 확인한다. 상대 응수가 1~2개로 좁아진 분기는 7수까지, 정적으로 패배(L)인 자리뿐 아니라 이미 나온 단어 때문에 새로 좁아진 함정 음절도 후보에 넣는다. 확인된 후보 중 가장 짧은 proof(=같은 깊이의 필승)를 가진 것들을 모아, 그중 상대 응수가 적은 쪽에서 고른다.
  3. **독배 전수 평가** — 첫 안전 수에서 멈추지 않고, 시간 예산 안에서 안전 후보를 모두 뜯어본다. 상대가 무엇으로 받아쳐도 (즉사 한방 / 이기는 자리 / 무승부 / 지는 자리) 중 가장 나쁜 값이 최대가 되는 수, 즉 상대의 숨통이 가장 조여지는 수를 고른다. 상대 응수 하나로 봇이 막히는 수는 안전 후보에서 뺀다. 최고 등급(그래프 승리 상태) 안에서 독배 점수 4점 이내 후보 중에서 고른다.
  4. **압박·점수** — 상대 후보가 1~3개뿐인 글자로 몰고, 같은 조건에서는 미션·장문으로 점수를 챙긴다.
- **선공 오프닝**: Lv.5 에서 봇이 먼저 두면(`봇부터`) 아무 글자나 잡지 않고, 봇이 이기는 자리(W3·W5)의 시작 글자로 연다. 0수 한방으로 1초 만에 끝나는 자리는 피하고(깊이 3수 이상), 최단 깊이 하나로 고정하지 않고 최단 +2수(최대 7수) 안에서 골라 매 판 다른 글자로 시작한다.
- **매 판 다른 수**: 같은 글자·같은 자리에서 15번 두면 서로 다른 단어가 Lv.4 평균 6.2종 · Lv.5 평균 5.0종 나온다(한방이 하나뿐인 자리처럼 선택지가 1개인 국면은 제외). 승률·한방 각 차단 같은 강도 기준은 그대로다.
- 판단은 한 수당 평균 2ms 안쪽(최대 10ms 이하), 응답 텀은 0.15~0.4초다.

### 봇 대 봇 벤치마크

`tools/bench.mjs` 가 브라우저 없이 `js/` 의 사전·봇 코드를 그대로 불러와, 엔진과 같은 규칙으로
봇끼리 대국한다(레벨·선공·시작 글자 고정, 결정적 난수). 1000판씩 측정한 승률이다.

| 대국 | 직전 Lv.5 선공 | 이번 Lv.5 선공 | 직전 Lv.5 후공 | 이번 Lv.5 후공 |
| --- | --- | --- | --- | --- |
| vs Lv.4 극악 | 94.2% | **99.0%** | 24.8% | **25.6%** |
| vs Lv.3 어려움 | 98.9% | 99.5% | 77.4% | 77.6% |
| vs 무작위 | 100% | 100% | 99.8% | 99.8% |

시작 글자에서 바로 한방이 나오는 자리를 빼고(수읽기만 남긴 조건) 같은 측정을 하면,
vs Lv.4 가 선공 88.0% → **98.0%**, 후공 51.0% → **52.5%** 다.
봇 선공 오프닝을 켜면 vs Lv.4 · vs Lv.3 모두 400판 전승(평균 3.4수)이고,
오프닝 글자는 500번 중 219종으로 흩어진다(모두 봇이 이기는 W등급).

```bash
/workspace/.local/node/bin/node tools/bench.mjs --games 1000 --levels 4,3,random --openings all
/workspace/.local/node/bin/node tools/bench.mjs --games 1000 --levels 4 --openings nokill --out downloads/bench.json
```

```
index.html          화면 뼈대

js/rules.js         한글 음절 분해 · 두음법칙

js/engine.js        턴 진행 · 판정 · 점수 · 타이머
js/bot.js           5단계 봇 전략(루트전 수읽기 포함)과 대사
js/audio.js         Web Audio 효과음(음원 파일 없음)
js/store.js         localStorage 설정 · 전적
js/ui.js            화면 조립, 입력, 결과

build/collect_kkuko.py 오픈DB(공개 API) 단어 수집
tools/verify.py     headless Chromium 검증(로컬/라이브)
tools/bench.mjs     봇 대 봇 승률 벤치마크(Node)
```

사전은 시작 음절마다 연속 구간을 이루도록 정렬해 두어, 브라우저에서는 이진 탐색과 구간 조회만으로
판정·후속 단어 수·봇 후보를 계산한다. 별도 색인 파일 없이 796,750 단어가 즉시 조회된다.

## 데이터 다시 만들기

```bash
curl -L -o db.sql https://raw.githubusercontent.com/JJoriping/KKuTu/master/db.sql
python3 build/build_data.py db.sql                      # db.sql 만으로 기존 사전 재생성
python3 build/collect_kkuko.py                          # 오픈DB 단어를 build/kkuko-words.txt 로 수집
python3 build/build_data.py db.sql build/kkuko-words.txt # 두 원본 병합 + 한방/유도 재계산
```

`build/collect_kkuko.py` 는 끄코 유틸리티의 공개 오픈API를 시작 음절별로 호출한다.
받은 원본(`build/kkuko-words.txt`, `build/kkuko-raw.jsonl`)은 저장소에 커밋하지 않는다.

## 검증

```bash
python3 tools/verify.py --local
python3 tools/verify.py --url https://kkeutmalbot.onrender.com
```

로컬/라이브 모두에서 콘솔·페이지 에러 0, 가로 오버플로 0, 두음법칙 입력, 중복 차단,
힌트 버튼·로직 삭제(버튼·단축키·사전 API 없음)와 입력 바 배치, 하드코어 모드(스위치·5초 고정·봇 선공·헤더/결과 배지·별도 전적·끄면 일반 모드 복귀),
내 단어장 제거(버튼·모달·사전 API 없음, 남은 localStorage 값 무시), 결과 화면 난이도 표시,
결과 화면 배틀 내역(버튼 열기/닫기·카드 안 세로 스크롤·턴/나·봇/단어/점수/태그 일치·0수 종료·긴 단어 줄바꿈·모바일 오버플로), 1단계 한방 금지, 4단계 극악 한방 즉사, 5단계 카드 배치, Lv.5 지옥의
한방 즉사·상대 한방 각 회피·강제 필승 검증·독배 압박·봇 선공 오프닝, Lv.4·Lv.5 단어 선택 다양성(같은 글자·같은 자리 15수에서 서로 다른 단어가 나오는지, 한방 즉사·최소 후속 수 강도 유지), 4단계 기준 localStorage 호환, 모바일 키보드 높이 레이아웃을 확인하고
스크린샷을 `downloads/`에 남긴다.
